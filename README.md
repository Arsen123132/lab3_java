# Activity Tracker

Android application in Java that tracks steps, estimated calories and distance using device sensors.

## Features
- Step Counter, Step Detector and Accelerometer fallback
- ACTIVITY_RECOGNITION runtime permission
- Daily reset
- Ukrainian and English localization
- Android Log-based application logger

## Run
1. Open the project in Android Studio.
2. Sync Gradle.
3. Run on a device or emulator with sensors.
